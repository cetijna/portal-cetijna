# Portal CETI José Nogueira de Aguiar

Site institucional estático do CETI José Nogueira de Aguiar (Esperantina — PI).

## Stack

- Vite + React + TypeScript
- Tailwind CSS v4
- Deploy via GitHub Pages

## Desenvolvimento

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
bun run preview
```
